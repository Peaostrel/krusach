# Автоматизация работы оптовой базы (Курсовой проект)

Информационная система для управления оптовой базой, разработанная на языке C# с использованием WPF и Entity Framework.

## Основные возможности

- **Управление товарами**: Просмотр, добавление, редактирование и удаление товаров на складе.
- **Работа с заказами**: Оформление заказов, отслеживание статусов.
- **Статистика и отчеты**: Визуализация данных о продажах и остатках.
- **Система аудита**: Логирование действий пользователей для обеспечения безопасности.
- **Темы оформления**: Поддержка светлой и темной тем.
- **Уведомления**: Интеграция с Email для отправки уведомлений.

## Технологический стек

- **Язык**: C#
- **Платформа**: .NET 8.0 (WPF)
- **База данных**: SQLite / SQL Server (Entity Framework Core)
- **Архитектура**: MVVM (Model-View-ViewModel)

## Структура проекта

- `krusach/` — Основной исходный код приложения.
- `Models/` — Модели данных и контекст БД.
- `ViewModels/` — Логика представления.
- `Services/` — Сервисы для работы с данными, почтой и аудитом.
- `Themes/` — Ресурсы оформления интерфейса.

## Как запустить

1. Убедитесь, что у вас установлен [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Peaostrel/krusach.git
   ```
3. Откройте файл `krusach.sln` в Visual Studio 2022.
4. Соберите и запустите проект (F5).
